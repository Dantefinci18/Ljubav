# Ljubav
Sitio web desarrollado para Ljubav, un local de pastelería. La página permite presentar el negocio, mostrar sus productos, compartir su historia y ofrecer diferentes medios de contacto.
Desarrollado con React y Vite, con diseño responsive, optimización SEO y una estructura de componentes reutilizables.

## Tecnologías
- React
- Vite
- JavaScript
- HTML
- CSS

## Requisitos
- Node.js

## Instalación y ejecución
```bash
npm install
```

```bash
npm run dev
```
